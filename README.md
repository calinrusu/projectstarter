# Simple web project starter

A simple script to create a starting structure for a web project.

## Requirements

- PHP 8.0+

## Project structure

	/myproject
		starter
		/app
			bootstrap.php
			/config
				app.php
				database.php
			/includes
				db.php
				functions.php
				csrf.php
				validation.php
			/lib
			/views
				/layouts
					head.php
					footer.php
				/partials
					navbar.php
				/pages
					index.php
		/public
			index.php
			/assets
				/css
					app.css
				/js
					app.js
				/img
